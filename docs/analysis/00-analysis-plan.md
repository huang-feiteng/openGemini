# openGemini 代码分析计划

本文档记录 openGemini 时序数据库代码仓库的系统性分析计划。

---

## 项目信息

- **项目名称**: openGemini
- **类型**: 云原生分布式时序数据库
- **语言**: Go 1.22+
- **许可证**: Apache 2.0
- **状态**: CNCF Sandbox 项目

---

## 分析目标

1. 理解整体架构和模块划分
2. 深入掌握存储引擎实现
3. 分析查询执行机制
4. 学习分布式系统设计
5. 提取性能优化技术

---

## 代码结构概览

```
openGemini/
├── app/                    # 应用程序入口 (5 个核心服务)
├── engine/                 # 核心查询引擎
├── services/               # 微服务层
├── lib/                    # 公共库 (71 个子模块)
├── config/                 # 配置文件
├── docker/                 # Docker 部署
├── python/                 # Python SDK
├── scripts/                # 脚本工具
└── docs/                   # 文档
```

## 执行原则

### 代码验证
- 每个文档完成后，必须回溯代码验证准确性
- 发现偏差及时修正文档
- 关键结论需标注代码位置

### 分析深度
- 每个模块选择 1-2 个核心文件精读
- 沿数据流/调用链追踪
- 避免过度深入细节

### 输出规范
- 文档使用 Markdown 格式
- 包含架构图和时序图
- 标注关键代码路径
- 记录技术亮点和设计决策
